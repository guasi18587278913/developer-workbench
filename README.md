# Developer Workbench

我的个人开发工作台。这里保存我在产品设计、AI 编程和独立开发中反复使用、确认有效的提示词、工具、检查清单和模板。

这不是资料收藏夹。只有真正解决过问题、以后还会继续使用的内容才放进来。

## 收录原则

1. **拿来就能用**：每个条目都写清适用场景、所需输入和使用方式。
2. **解决具体问题**：不收泛泛的方法论，只收能推动开发工作的材料。
3. **先小后大**：需要什么再增加什么，不提前搭建复杂分类。
4. **不存秘密**：API Key、Token、账号、客户数据和内部敏感信息不得提交。

## 后续怎么扩展

出现第二类内容时再按需增加目录，例如开发工具、检查清单和项目模板。每个新条目至少要回答三个问题：什么时候用、怎么用、什么结果算有效。
