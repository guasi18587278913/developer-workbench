## 方法类内容的收录原则

产品点子随手记，不设门槛。提示词、工具、Skill 和模板不是资料收藏夹，只有真正解决过问题、以后还会继续使用的才放进来：

1. **拿来就能用**：每个条目都写清适用场景、所需输入和使用方式。
2. **解决具体问题**：不收泛泛的方法论，只收能推动开发工作的材料。
3. **先小后大**：需要什么再增加什么，不提前搭建复杂分类。

**不存秘密**对整个仓库都适用：API Key、Token、账号、客户数据和内部敏感信息不得提交。
