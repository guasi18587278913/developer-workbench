## 核心痛点

用 AI（ChatGPT/Claude）生成的代码，表面跑得通，内部一团糟：
- Stripe 支付集成完全跑不通
- 零状态管理、重复调用接口、无错误处理
- 冗余代码大量堆积（上手第一天删了2000行）

**数据佐证：**
- Reddit r/EntrepreneurRideAlong 帖子「I'm fixing vibe-coded apps」152条评论，全职靠修复AI代码为生
- X @tom_doerr 「用 AI 写代码最大的错误，是让它修bug而不是回滚」— 3784赞/39万浏览
- B站热评：「AI编程在复杂业务场景下，调教时间反而超过手写」512赞
- 斯坦福大学已开课 CS146S 专门教 Vibe Coding

---

## 产品方向

用户上传代码仓库，自动扫描三类问题：
1. **安全漏洞**：数据库权限错误、API Key 写死在代码里
2. **架构问题**：重复调用、冗余代码、无状态管理
3. **支付集成**：Stripe 接口调用不规范

扫描后生成「体检报告」，红绿灯呈现，非技术人员也能看懂。

先从最常见技术栈入手：**Supabase + Next.js**（当前 Vibe Coding 最常用搭配）

---

## 小瓜子的评估

**赛道是真的，时机是对的。**

⚠️ 核心疑虑：「卖报告」定价悬空
- 技术人员：自己看代码就能判断，有免费工具（SonarQube/ESLint/GitHub Security）
- 非技术人员：看到红灯了，然后呢？还是不会修，报告价值打折

**更有价值的方向：「卖修复」而不是「卖报告」**
- Reddit 那位发帖者是靠直接帮人修赚钱，不是卖报告
- 产品进化路径：扫描（免费入口）→ 报告 → **对接修复者**（服务市场才是护城河）

**MVP 验证建议：**
先在独立开发者社区发帖定价测试「帮你扫一遍AI写的代码+标出问题+给修复建议」，看有没有人付钱——比先做工具再找用户快得多。

---

## 商业模型

- 免费扫描 + 付费看完整报告（49美元/份）
- 月订阅 29美元（持续监控）
- 长期：进化成修复服务市场（连接修复者和客户）
