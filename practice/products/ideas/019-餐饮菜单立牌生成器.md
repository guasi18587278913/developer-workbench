## 核心思路

把"用 AI 生成餐厅展架/立牌/菜单海报"这件事，封装成一个**给餐厅老板用的网站或小程序**：

- 老板上传 / 选一道菜 → 选风格（轻食风 / 山野风 / 浓郁风 / 夜市风…）→ 填卖点 → 一键出图
- 输出可直接用于门店物料：异形展架、立牌、桌牌、外卖海报、套餐促销图
- 老板不用懂提示词、不用会 ChatGPT、不用找设计师，**点几下就出图**

## 用户是谁

- 中小餐饮老板（夫妻店、单店、小连锁）
- 新店开业 / 新品上新 / 套餐促销时急需物料
- 没设计师、不会用 AI、又不想花钱外包

## 用户付费理由

- 一张海报外包至少 100–300，AI 生成几块钱、几十块包月
- 自己用 ChatGPT 不会写提示词、不会调参、出图不像
- **省钱 + 省时 + 不用学**

## 产品形态可能性

- **网站**：上传图 + 选风格 + 填字 → 出图 / 出多图 → 下载或直接生成印刷文件
- **小程序**：更适合餐饮老板（手机操作）——朋友圈分享、转发同行
- **轻量先试**：先做一个 Notion 模板 / 飞书多维表格表单，跑用户验证

## 差异化（vs 现成 AI 海报工具）

- 现有 Canva / 创客贴：模板多但要自己拼，老板不会
- 现有 AI 海报工具：通用，不懂餐饮专属语言（异形展架尺寸、菜品摆拍、餐饮风格分类）
- 这个：**只服务餐饮、模板预设好、风格预选、文案预填**

## 待验证

- [ ] 餐饮老板真的会自己上手做物料吗？还是甩给设计师？
- [ ] 输出物对印刷质量要求高不高（300dpi / 出血线 / CMYK）
- [ ] 第一批种子用户从哪来（社群 / 餐饮老板抖音号 / 街边发卡片）
- [ ] 提示词体系够不够覆盖菜系（中餐 / 西餐 / 烘焙 / 茶饮 / 火锅 / 烧烤）
- [ ] 国内合规：图片版权、菜品摆拍 vs AI 生成宣传是否合规
