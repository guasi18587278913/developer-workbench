# 023 AhaPrompt（对标研究·AI 提示词内容站）

**状态**：💡 对标研究
**创建**：2026-09-08
**灵感来源**：[X @weijunext 9/7 推文](https://x.com/weijunext/status/2096824187570778304)（298 赞 / 54 转 / 78 回复 / 1.9 万浏览）
**对标产品**：AhaPrompt
**网址**：<https://ahaprompt.app>
**一句话**：把推特上散落的优质 AI 出图/出片提示词，用 Agent 采集翻译 + 人工精选，做成一个免费、多语言、按模型分类的提示词库。

---

## 解决什么问题

会用 AI 生图生视频的人越来越多，但**大部分人打不开"空白输入框"这一关**。Sora、Seedance、Nano Banana 这类模型，效果好坏几乎全在提示词，而好提示词都散落在推特、Discord、小圈子里，中文用户还隔着一层语言。

AhaPrompt 的定位就写在首页标语里：`Skip the blank page. Paste the aha.`——不用自己写，直接复制粘贴。

## 用户是谁

- 不会写图片/视频提示词的普通创作者（推文原话点的就是这群人）
- 自媒体内容生产者：小红书、抖音、油管封面和短片
- 想快速试模型效果、但懒得调参的开发者和产品经理
- 中日韩非英语母语用户（站点做了四语言）

## 产品形态（实际扒下来的结构）

- **规模**：宣称 800 条精选提示词、覆盖 20 个模型
- **三种媒介**：图片 / 视频 / 音频，各自独立筛选入口
- **按模型建站中站**：`/models/seedance`、`/models/nano-banana-pro`、`/models/veo-3` 等 20 个独立模型落地页，覆盖 ByteDance、Google、OpenAI、xAI、快手、MiniMax、Runway、阿里、Suno、ElevenLabs
- **按风格打标**：Portrait、Poster、Anime、Cinematic、Typography、VFX、Watercolor…… 几十个风格标签，每个都是一个页面
- **四语言**：`/en` `/zh` `/ja` `/ko`
- **交互**：一键复制完整提示词（含参数）、收藏、用户投稿入口 `/submit`、博客 `/blog`
- **门槛**：浏览不需要注册，全部免费

## 变现方式（页面代码里能直接看到）

站点挂了 **Google AdSense**（`ca-pub-4885097147285432`）。目前看不到付费墙、订阅或会员，首页反复强调 "Free forever"。

也就是说这是一个**纯免费内容站 + 广告变现**的模型：靠 SEO 搜索流量做规模，用广告位收钱。这类站的天花板取决于流量，但启动成本和运营人力极低。

## 最值得抄的三件事

**1. 内容生产是个飞轮，不是靠人写**

推文原话：Agent 自动采集、翻译推特上的热门优质提示词 → 人工审核 → 精选发布。

这是典型的"**AI 干脏活、人做把关**"的分工。800 条内容如果纯人工，成本高到做不起来；如果纯 AI，质量撑不住信任。它切在中间：采集和翻译交给机器，"这条到底好不好"留给人。任何"公域有大量优质碎片内容、但散乱且缺中文版"的领域，都能套这个结构。

**2. 用页面数量吃搜索长尾（programmatic SEO）**

20 个模型页 × 几十个风格标签 × 4 种语言，页面数量是乘出来的。用户搜的从来不是"提示词库"，而是"Seedance 2.5 提示词怎么写"、"Nano Banana 人像 prompt"这种带模型名的长尾词——**每一个组合都对应一个已经存在的页面**。

模型名还是天然的流量红利：新模型一发布，全网都在搜它的名字，而这个站的模型页可以第一时间上线。

**3. 站点本身是自家 SaaS 模板的样板间**

页脚写着 `Built with NEXTY.DEV`。nexty.dev 正是发推的 weijunext 自己在卖的 Next.js SaaS 模板。

所以这条推文表面是"推荐一个网站"，实际同时在演示模板能做出什么东西。**做工具的人自己下场用工具做产品，再拿产品反过来给工具引流**——这套打法比直接打广告可信得多，值得单独学。

（注意：站点的数据统计脚本挂在 `rybbit.wenext.dev` 和 `p.wenext.dev` 上，域名和 weijunext 高度相似，但主域访问不通，无法确认所有权。这站到底是他自己做的、还是模板客户做的，**没有验证，先别当结论用**。）

## 小团队怎么抄

直接做一个"中文版 AhaPrompt"意义不大——AhaPrompt 本身已经有中文站了。值钱的是把这套**采集 → 翻译 → 精选 → 按维度切页面**的结构，搬到别的内容洼地：

- **垂直到具体职业**：电商主图提示词库、房产/餐饮/医美行业的出片提示词，每个行业有自己的构图和合规讲究，通用库解决不了
- **换媒介**：Claude Code / Cursor 的编程提示词库、Agent 工作流模板库——同样是散落在推特、同样缺中文、同样有模型名长尾词
- **换信息源**：AhaPrompt 只采推特，小红书、B 站、YouTube、Reddit 上的优质提示词还没人系统性搬运（这块和已有的 [[004-Reddit需求监控工具]]、[[020-对标选题日报-飞书多客户推送方案]] 的采集能力是同一套底子）
- **加一层生成**：库只是入口，真正的付费点可能在"根据你的需求改写提示词"——从查字典升级成写作助手

## 待验证

- [ ] 实际流量多少？（用 SimilarWeb 或看它的 rybbit 公开面板）——这是广告变现模型的唯一命门
- [ ] 800 条提示词里，Agent 采集和人工筛选各花多少时间？内容飞轮的真实人力成本
- [ ] 上线多久做到 800 条？增长速度决定了这套打法能不能快速起量
- [ ] AdSense 这类内容站的实际收入量级（每千次展示能收多少），够不够养活项目
- [ ] 提示词的版权问题：搬运推特上别人写的提示词并翻译发布，法律边界在哪
- [ ] `wenext.dev` 到底是不是 weijunext 名下，用于确认"自家模板样板间"这个判断
