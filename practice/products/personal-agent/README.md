# Personal Agent 个人助手

长期陪伴用户学习、讨论和生活的个人助手。保留长期记忆、自主活动和主动交流，以自媒体创作为当前切入点；热点创作助手、选题收藏夹和收藏助理属于首批扩展方向，后续能力可以继续增加。

2026-10-27 将项目开发方案归入本开发库，便于与原始产品想法一起查阅。
