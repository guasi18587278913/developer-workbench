# Personal Agent：本轮搭建范围

2026-10-26，用户确认开始。

## 已确认

- 产品本体是长期陪伴的个人助手。学习陪伴保留，自媒体是首个能力扩展方向。
- 尽量还原 W4S1「独一无二的 TA」的七项能力：首次设置、日常回应、对话方法、记忆、主动联系、角色生活、记忆维护。
- 首批增加选题收藏夹和持续发现选题；后者调用既有 topic-partner。功能列表可以扩展，不把产品限定为这两项。
- 各能力共用角色、用户记忆、关系和主动联系判断。角色设定中的经历与实际读取的资料分开存储、引用。

## 实现顺序

1. 保存原始来源及哈希，导入课程角色卡，建立独立工作区。
2. 实现单用户文件存储、两段式初始化、一次上下文装配、记忆与对话记录、纠正和停用。
3. 按课程还原七项 Skill，逐项记录本地适配和未验证项。
4. 增加收藏、真实资料登记、选题候选和统一主动消息出口。
5. 实现可手动执行的后台任务与运行适配；先做离线验证，真实后台和消息接入按用户选择启用。
6. 运行行为测试、独立审查和受影响回归，交付可启动入口和明确的剩余配置项。

## 尚待选择，不作为已定需求

- 日常聊天及主动消息入口（已向用户询问）。
- 后台模型运行方式、允许调用次数或费用上限、常驻运行位置。
- 新闻/热点来源和采集频率；收藏内容外部提取服务的费用。
- 用户选择的角色、关系起点、主动联系时段和话题边界。

## 当前外部操作边界

本轮可完成本地源码、技能、离线数据测试及只读资料查询。实际配置凭证、启动常驻调度、付费探活、发送消息和部署，需要对应范围的明确授权。不会把模拟结果记录为真实送达或正式用户使用。

## 完成判断

- 本地数据在重新打开后可读，记忆纠正后旧值不再参与上下文。
- 收藏资料、角色虚构经历、用户事实有可观察的来源边界。
- 关闭两个扩展后，学习与陪伴核心仍然完整。
- 主动消息在关闭、勿扰、冷却、重复、未回复等条件下不发送；未知送达不盲目重试。
- 后台无新消息时不制造记忆；失败不推进处理水位。
- 结果分别报告：结构检查、确定性行为测试、独立行为体验、真实模型运行、真实消息/后台运行。
