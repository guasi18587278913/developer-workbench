# 013 - AI 面试模拟器

**阶段**：💡 灵感/需求验证
**记录时间**：2026-03-30
**来源**：小红书评论区需求调研

---

## 核心方向

**AI 驱动的面试模拟练习工具（网页版）。**

用户输入岗位 JD 或选择岗位类型，AI 自动生成针对性面试题，支持语音/文字作答，AI 实时点评打分，帮助求职者高效备面。

---

## 为什么这个方向

### 需求信号（小红书实测数据）

- 「自己做了个面试小程序｜求大家提需求」— **5749 赞**，评论区"蹲网址"刷屏
- 覆盖人群广：校招、社招、考研复试都有强需求
- 高赞需求评论：
  - "根据岗位 JD + 企业名称针对性出题"（23 赞）
  - "社招也有需求"（10 赞）
  - "考研复试急需"（多条）
- 现有竞品体验一般，"和直接问 DeepSeek 区别不大"的吐槽说明工具化做得不够

### 竞争优势

- 已有产品多为小程序，网页版有差异化空间
- AI 编程工具（Claude Code）可快速实现全栈
- 技术栈简单：前端 + LLM API，一个人可搞定

---

## 产品功能设想

| 功能 | 描述 | 优先级 |
|------|------|--------|
| **JD 智能出题** | 输入 JD / 企业名 / 岗位类型，AI 生成针对性面试题 | P0 |
| **模拟面试** | 逐题作答（文字/语音），AI 实时追问 | P0 |
| **AI 点评打分** | 每题评分 + 改进建议 + 整体报告 | P0 |
| **复盘记录** | 历史面试记录、薄弱点追踪 | P1 |
| **专属题库** | 用户上传自己的题，创建个人题库模拟 | P1 |
| **岗位分类题库** | 产品、技术、运营、设计等分类题库 | P2 |
| **考研复试模式** | 针对院校/专业的复试问题生成 | P2 |

---

## 变现模式

| 模式 | 描述 |
|------|------|
| **免费体验** | 每天 3 次免费模拟 |
| **会员订阅** | 月付/年付，无限模拟 + 详细报告 + 历史记录 |
| **单次购买** | 按场景买（如"产品经理面试包"） |

---

## 技术方案（初步）

- **前端**：Next.js / React，部署 Vercel
- **后端**：API Routes / Edge Functions
- **AI**：Claude API / DeepSeek API（面试问答 + 评分）
- **语音**：Web Speech API（浏览器原生）
- **数据库**：Supabase / Prisma + PostgreSQL
- **认证**：NextAuth / Clerk
