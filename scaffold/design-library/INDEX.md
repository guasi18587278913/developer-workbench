# 设计素材目录

给 AI 和自己用的设计参考入口：701 份 Framesbase 素材，另有库外参考。先按要做的事选一个入口，只读用得上的文件。

## 按要做的事找

- 改进或替换页面里的某一块（导航、首屏、价格区、页脚、手机底部导航等）：看[按组件找](components/README.md)。
- 审一个现有页面，找能做得更好的地方：按 [AGENTS.md](AGENTS.md) 里“审现有页面”的步骤走。
- 找整页风格方向（行业、明暗、配色）：用 [README](README.md) 里的检索命令，或按下面的栏目浏览。
- 找背景图、背景视频：看[动态背景](by-section/backgrounds.md)，每条有中文画面描述。
- 找动效：看[动效做法](components/motion.md)，以及[库外参考](references.md)里的开源动效库。
- 要带源码的区块：看[库外参考](references.md)里的 reactbits-preview。
