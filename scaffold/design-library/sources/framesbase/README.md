## 保存了什么

提示词类保存原始正文，按照页面显示字符数核对，并记录 SHA-256 内容校验值。每条元数据保留原始标题、分类、栏目和定位信息。

源码链接类保存原始链接与可取得的源码快照。快照绑定具体 Git 提交，文件清单及校验值见 `source-receipt.json`。不运行第三方源码。许可证文件若存在则保留；未找到时明确记录 `not-found`。

背景类保留原始下载链接和本地静态预览。根据用户选择，不把全部视频存进 Git；可用仓库工具按需下载。

预览统一用于选图：最大边 960 像素、WebP 格式。动图取一个静态帧，处理参数记入 `preview_processing`。采集时的原始预览保存在采集机器的本地缓存，不属于 GitHub 归档。

## 没有声称完成的工作

没有把所有提示词生成代码，没有验证每份设计在各平台的实际效果，也没有离线保存提示词中引用的全部第三方字体、图片和视频。使用某条素材时，应检查其外部依赖和目标平台兼容性。

## 完整性与失败处理

- `collection-report.json`：整批栏目预期数量、实际条目编号、重复和失败记录。
- `runs/`：历次采集记录，保留失败证据；补采完成后不能删除原失败记录伪装一次成功。
- `manifest.json`：当前本地内容校验结果，包含各类数量、哈希、有效预览和目录路径检查。
- 每条 `metadata.json`：交付类型、原始定位、文件路径、下载与实现状态。

没有稳定详情 URL 的卡片，通过首页、栏目、标题与原站编号定位。背景没有公开条目编号时，使用原始交付链接的校验值生成本地编号。

页面数量变化、未取得正文、重复或文件缺失都应明确报告。临时预览链接只在当前会话中用于下载，不写入元数据；来源资料本身的普通外链保留原样。

4 条原始提示词还包含第三方素材的签名或令牌链接，共 9 处。这些是原文引用的图片和视频素材地址，不是本次会员登录凭证；原文保留，检索目录不复制这些参数。它们未来可能失效，使用对应条目时需检查资源是否仍可访问。
